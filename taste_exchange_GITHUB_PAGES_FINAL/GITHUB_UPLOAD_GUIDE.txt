취향 교환일기 - GitHub Pages 업로드용

업로드할 파일:
- index.html
- .nojekyll
- README.txt (선택)
- supabase_setup.sql (사이트 실행에는 필요 없지만 백업용으로 포함)

GitHub Pages 설정:
1. 새 repository 생성
2. 위 파일들을 repository 최상단(root)에 업로드
3. Settings > Pages
4. Source: Deploy from a branch
5. Branch: main / (root)
6. Save
7. 배포 완료 후 Visit site

Supabase는 기존 프로젝트를 그대로 사용하므로 SQL을 다시 실행할 필요 없습니다.
